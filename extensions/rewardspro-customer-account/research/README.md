# Customer Account Extension Research Program

Use this research plan to close the knowledge gaps that block a production-ready loyalty experience on Shopify’s new customer accounts. Each companion brief in this folder dives into a specific dimension (UX, CLI, architecture, delivery, etc.) with concrete research tasks, primary questions, and suggested sources.

## How to Work Through These Briefs
1. Skim all topic files to understand scope and sequencing.
2. Prioritize the briefs that unblock current milestones (profile dashboard first, then order-status/banner).
3. Capture findings, links, and code samples in a shared notebook or Notion doc; note open questions.
4. Feed insights back into implementation tickets and update this folder if new gaps appear.

## Topic Map
- `best-practices.md`: Customer account UX + loyalty-specific design guidance.
- `cli-and-tooling.md`: Shopify CLI, local dev tooling, and automation practices.
- `extension-architecture.md`: Front-end execution model, module boundaries, and data flow.
- `customer-facing-display.md`: Rendering surfaces, layout constraints, accessibility, and localization.
- `backend-integration.md`: Session tokens, API contracts, security, and performance resiliency.
- `testing-and-debugging.md`: Verification workflows, logging, observability, and QA pipelines.
- `deployment-and-ops.md`: Packaging, versioning, release, and operational monitoring (optional stretch).
